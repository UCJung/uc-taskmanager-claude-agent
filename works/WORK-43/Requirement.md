# Requirement — WORK-43

## Original Request
> 보그보글 만들어줘 full 모드 자동으로

## Functional Requirements (기능 요구사항)
- FR-01: 4x4 격자에 랜덤 알파벳을 배치하는 보드 생성 기능
- FR-02: 인접한 셀(가로/세로/대각선 8방향)을 드래그 또는 클릭하여 글자를 연결하는 단어 입력 기능
- FR-03: 입력된 단어의 유효성 검증 (사전 기반 단어 확인 + 경로 유효성 확인)
- FR-04: 점수 계산 시스템 (단어 길이에 따른 점수 부여: 3글자=1점, 4글자=1점, 5글자=2점, 6글자=3점, 7글자=5점, 8+글자=11점)
- FR-05: 제한 시간(3분) 타이머 기능 및 게임 종료 처리
- FR-06: 게임 재시작 (새 보드 생성) 기능
- FR-07: 찾은 단어 목록 표시 및 중복 입력 방지

## Non-Functional Requirements (비기능 요구사항)
- NFR-01: HTML/CSS/JS로 구현, 브라우저에서 바로 실행 가능 (서버 불필요)
- NFR-02: 반응형 레이아웃 (모바일/데스크탑 대응)
- NFR-03: 영어 사전 데이터를 내장하거나 경량 사전 파일을 포함

## Acceptance Criteria
- [ ] index.html을 브라우저에서 열면 4x4 보글 보드가 표시된다
- [ ] 인접 셀을 드래그하여 단어를 만들 수 있다
- [ ] 유효한 영어 단어만 점수로 인정된다
- [ ] 3분 타이머가 동작하고 시간 종료 시 게임이 끝난다
- [ ] 점수가 Boggle 공식 규칙에 따라 계산된다
- [ ] New Game 버튼으로 새 게임을 시작할 수 있다
- [ ] 이미 찾은 단어는 중복 입력되지 않는다
