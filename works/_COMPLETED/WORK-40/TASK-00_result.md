## 주요 기능

### 게임 메커니즘
- **방향키 조작**: 상하좌우 화살표 또는 WASD로 뱀 이동
- **먹이 시스템**: 먹이 먹을 때마다 점수 +10, 뱀 길이 증가
- **동적 속도 증가**: 점수 10점마다 이동 속도 10ms 빨라짐 (최대 60ms)
- **충돌 감지**: 벽 및 자기 몸에 충돌 시 게임 오버
- **일시정지**: 스페이스바로 일시정지/재개

### UI/UX 기능
- **점수 표시**: 현재 점수 및 최고점 실시간 표시
- **최고점 저장**: localStorage 사용하여 페이지 새로고침 후에도 유지
- **게임 오버 화면**: 최종 점수 표시 및 재시작 버튼
- **시각 효과**: 뱀 머리 눈 표현, 격자 배경, 그라데이션 투명도

### 기술 스택
- HTML5 Canvas API (렌더링)
- Vanilla JavaScript (게임 로직)
- CSS3 (UI 스타일링)
- localStorage API (데이터 저장)
