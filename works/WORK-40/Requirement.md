# Requirement — WORK-40

## Original Request
> snake 게임을 만들고 토큰사용량 확인

## Functional Requirements
- FR-01: Snake 게임을 단일 HTML 파일로 구현한다 (HTML + CSS + JavaScript 포함)
- FR-02: 기본 Snake 게임 기능 — 방향키 조작, 먹이 획득, 점수 표시, 충돌 시 게임 오버

## Non-Functional Requirements
- (없음)

## Acceptance Criteria
- [ ] 단일 HTML 파일을 브라우저에서 열면 Snake 게임이 즉시 실행된다
- [ ] 방향키(화살표)로 뱀을 조작할 수 있다
- [ ] 먹이를 먹으면 뱀이 길어지고 점수가 증가한다
- [ ] 벽 또는 자기 몸에 충돌하면 게임 오버 처리된다
- [ ] 게임 오버 후 재시작이 가능하다
